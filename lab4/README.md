# Лабораторная работа 4. Двухслойный перцептрон

## Что сделано

Реализован двухслойный перцептрон: входной слой получает 24 признака, скрытый слой использует ReLU, а выходной слой предсказывает `logP`. Обучение написано на NumPy с вычислением градиентов и методом Adam. Перед обучением признаки и целевая переменная стандартизуются, а прогноз возвращается в исходной шкале `logP`.

Обучаются модели со скрытым слоем из 2, 4, 8, 16 и 32 нейронов. Дополнительно сравниваются вариант с постоянной скоростью обучения, вариант с уменьшением шага на каждой итерации и `MLPRegressor` из scikit-learn.

## Запуск

Запустить эксперимент:

```bash
python main.py
```

Можно задать файл данных, каталог результатов и максимальное число итераций:

```bash
python main.py --data путь/к/lipo.csv --output results --max-iter 12000
```

В каталоге результатов сохраняются таблица сравнения моделей и отдельные CSV с фактическими значениями, прогнозами и остатками для каждой ручной модели.

## Публичный интерфейс

В `model.py` доступны:

- `load_data(path=None)` - загрузить данные;
- `TwoLayerPerceptron(...)` - создать модель;
- `fit(X, y)` - обучить модель;
- `predict(X)` - получить прогноз;
- `regression_metrics(y_true, y_pred)` - рассчитать MSE, RMSE и R²;
- `compare_models(frame=None, path=None, max_iter=20000)` - запустить сравнение пяти размеров скрытого слоя и модели scikit-learn.

## Результаты эксперимента

На приложенном наборе из 82 веществ получились следующие значения на обучающей выборке:

| Модель | Итерации | Сошлась | RMSE | R² |
|---|---:|:---:|---:|---:|
| Ручная, 2 нейрона | 12000 | Нет | 0.5506 | 0.8805 |
| Ручная, 4 нейрона | 12000 | Нет | 0.2266 | 0.9798 |
| Ручная, 8 нейронов | 1810 | Да | 0.1308 | 0.9932 |
| Ручная, 16 нейронов | 1283 | Да | 0.1238 | 0.9940 |
| Ручная, 32 нейрона | 2103 | Да | 0.1237 | 0.9940 |
| Ручная, 8 нейронов, постоянный шаг | 1811 | Да | 0.1299 | 0.9934 |
| scikit-learn, 8 нейронов | 1666 | Да | 0.1405 | 0.9922 |

В этих запусках модели с 2 и 4 нейронами не достигли критерия остановки до лимита в 12000 итераций. При 8, 16 и 32 нейронах обучение завершилось раньше. На обучающей выборке лучше всего показали себя варианты с 16 и 32 нейронами, но разница между ними практически отсутствует.

Постоянный и уменьшающийся шаг дали близкие результаты. Реализация с уменьшающимся шагом использует формулу `learning_rate / (1 + decay * (iteration - 1))`. При выбранном небольшом `decay` уменьшение достаточно плавное.

R² около 0.994 выглядит очень высоким, однако все 82 наблюдения использовались для обучения и оценки. Поэтому эти метрики показывают качество подгонки, а не качество на новых молекулах. Небольшой размер набора также повышает риск переобучения.
