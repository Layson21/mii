# Лабораторная работа 3. Линейная регрессия

## Что сделано

Программа оценивает линейную регрессию для предсказания `logP` по 24 характеристикам молекул из `lipo.csv`. Коэффициенты находятся методом наименьших квадратов. Также рассчитываются остатки, оценка дисперсии ошибки, стандартная ошибка регрессии, R² и 95-процентные доверительные интервалы для коэффициентов по t-распределению.

## Запуск

Запуск расчёта:

```bash
python main.py
```

Если файл данных лежит в другом месте, можно указать путь:

```bash
python main.py --data путь/к/lipo.csv --output results
```

В каталоге результатов будут `coefficients.csv` и `residuals.csv`.

## Публичный интерфейс

В `model.py` доступны функции:

- `load_data(path=None)` - загрузить таблицу;
- `fit_ols(frame)` - обучить модель и получить коэффициенты, прогнозы, остатки и статистики;
- `predict(frame, coefficients)` - посчитать прогноз для таблицы;
- `run_analysis(path=None)` - выполнить расчёт и вернуть результат с таблицей коэффициентов.

## Результаты на исходных данных

В таблице 82 вещества и 24 регрессора. Оценка R² равна **0.837989**, то есть модель описывает около 83.8% разброса `logP` на этой выборке. Остаточная дисперсия `s² = 0.590964`, стандартная ошибка регрессии `s = 0.768742`. Число степеней свободы для остаточной дисперсии - 57.

Самые большие по модулю оценки коэффициентов получились у `RBr` (1.7566), `RSR` (1.3211), `ROPO3` (1.1465) и `HBA2` (1.0234). Но это не означает, что именно они обязательно важнее всех остальных: признаки измеряются в разных единицах, а между ними может быть зависимость.

По R² модель выглядит достаточно хорошо для описания имеющейся выборки, но этого недостаточно, чтобы утверждать, что она хорошо предсказывает новые вещества. В выборке всего 82 наблюдения при 25 оцениваемых параметрах вместе со свободным членом. Некоторые доверительные интервалы широкие и включают ноль. Это говорит о неточности отдельных оценок.
