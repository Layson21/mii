# Лабораторная работа №1

## Метод Якоби для расчёта собственных векторов и собственных чисел

В программе реализован метод Якоби для действительной симметричной матрицы. Для работы с матрицами используется библиотека NumPy,
готовые функции поиска собственных чисел и векторов не используются.

На каждом шаге выбирается недиагональный элемент матрицы и зануляется с помощью поворота. После завершения метода элементы главной диагонали являются собственными числами, а столбцы матрицы собственных векторов являются соответствующими собственными векторами.

## Структура проекта

- `jacobi_method/solver.py` - реализация метода Якоби;
- `jacobi_method/__init__.py` - публичный интерфейс;
- `tests/test_solver.py` - тесты;
- `pyproject.toml` - описание пакета.

## Публичный интерфейс

Основная функция программы:

```python
jacobi_eigen(matrix, epsilon=1e-10, max_iterations=100000)
```

`matrix` - действительная симметричная матрица.

`epsilon` - требуемая точность вычислений.

`max_iterations` - максимальное число итераций, которое не позволяет программе зациклиться.

Функция возвращает два значения:

```python
eigenvalues, eigenvectors
```

`eigenvalues` - массив собственных чисел.

`eigenvectors` - матрица, в столбцах которой находятся собственные векторы.

## Алгоритм

В начале создаётся копия исходной матрицы и единичная матрица собственных векторов. Затем вычисляется сумма квадратов недиагональных элементов выше главной диагонали.

Для выбранного элемента `A[p, q]` вычисляется величина

```text
C = (A[q, q] - A[p, p]) / (2 * A[p, q])
```

После этого по формулам 
вычисляются тангенс, косинус и синус угла поворота.

Далее пересчитываются диагональные элементы, элементы строк и столбцов `p` и `q`, а `A[p, q]` становится равен нулю. Одновременно пересчитываются два соответствующих столбца матрицы собственных векторов.

После зануления сумма квадратов недиагональных элементов уменьшается на квадрат занулённого элемента. Работа алгоритма заканчивается, когда эта сумма становится меньше `epsilon`.

Элементы для зануления перебираются последовательно выше главной диагонали.

## Проверка входных данных

Перед вычислением проверяется, что матрица непустая, квадратная, симметричная и содержит конечные числовые значения. Также проверяется значение точности и максимального количества итераций.

Если входные данные неправильные, программа завершает работу с предусмотренной ошибкой. Если число итераций превысило `max_iterations`, возникает `RuntimeError`.

## Пример использования

```python
import numpy as np
from jacobi_method import jacobi_eigen

matrix = np.array([
    [4.0, 1.0, 1.0],
    [1.0, 3.0, 0.0],
    [1.0, 0.0, 2.0],
])

eigenvalues, eigenvectors = jacobi_eigen(matrix)

print(eigenvalues)
print(eigenvectors)
```
