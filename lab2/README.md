# RIG — Relative Identity Geometry для Vehicle Re-ID

## Идея

**Гипотеза:** различие между признаками двух автомобилей может быть устойчивее к смене ракурса, чем признаки каждого автомобиля по отдельности.

Вместо требования одинаковых эмбеддингов машины спереди и сзади предлагается сохранять **относительные различия** между двумя машинами при изменении ракурса.

Пусть `A` и `B` — разные автомобили, а индексы `1` и `2` — два сопоставимых ракурса. ResNet-50 с общими весами извлекает признаки `a₁`, `a₂`, `b₁`, `b₂`.

Новая функция потерь:

$$
L_{RIG}=\left\|(a_1-b_1)-(a_2-b_2)\right\|_2^2.
$$

Интуиция: если влияние ракурса на признаки машин примерно одинаково, оно сократится при вычитании:

$$
f(A,v)=u_A+s_v,\qquad f(A,v)-f(B,v)=u_A-u_B.
$$

## Реализация

- **Backbone:** предобученный ResNet-50, эмбеддинг 256–512 измерений.
- **Обучающая четвёрка:** два разных автомобиля, каждый снят в двух сопоставимых ракурсах.
- **Общая функция потерь:**

$$
L=L_{CE}+\alpha L_{Triplet}+\beta L_{RIG}.
$$

```python
import torch.nn.functional as F

def rig_loss(a1, b1, a2, b2):
    return F.mse_loss(a1 - b1, a2 - b2)
```

## План эксперимента

1. Собрать объединённый датасет из открытых Vehicle Re-ID наборов, согласовать идентификаторы и разметку ракурсов; исключить утечку одних и тех же автомобилей между train/test.
2. Обучить базовый ResNet-50 с `Cross-Entropy + Triplet Loss`.
3. Добавить RIG Loss с несколькими значениями `β` (например, `0.05`, `0.1`, `0.2`).
4. Сравнить **Rank-1** и **mAP**, отдельно на парах с сильно различающимися ракурсами.

## Ограничения и новизна

- Ракурс может скрывать уникальные детали, поэтому равенство относительных различий выполняется не всегда.
- Для обучения нужны подходящие четвёрки изображений; может потребоваться приблизительная группировка ракурсов.
- **Научная новизна не подтверждена:** существуют родственные работы по viewpoint-invariant Re-ID и относительному обучению признаков. Нужна отдельная проверка литературы и эквивалентных функций потерь.

**Ожидаемый результат:** проверить, повышает ли сохранение относительной геометрии признаков точность Vehicle Re-ID при больших изменениях ракурса. Улучшение не гарантируется.
